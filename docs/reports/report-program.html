§1 Orientation

Floatsam is a shipped, live underwater arcade game built on an unusual foundation: the entire game is a deterministic, headless simulation with fairness proven by the thousands of runs — not by playtest vibes.

You tap or dive a sea creature through gaps in a reef. Under the hood, a pure-TypeScript fluid-physics core (zero rendering dependencies) runs a fixed-timestep simulation seeded so every run is exactly reproducible. That property is the project's spine: it lets us freeze a "golden" reference run, machine-verify fairness across 80,000 seeded runs, and add features behind hard regression gates.

§3 Engineering pillars

Three properties make the codebase unusually safe to extend, and are worth protecting in every future decision:

  • Determinism. A seeded, fixed-timestep, Phaser-free simulation core. Same seed ⇒ same run, every platform. Enables replay, golden masters, and headless fairness testing.
  • Fairness by construction. Difficulty is bounded by derived reachability clamps and (for currents) a budget clamp anchored to the weakest creature — so "is this beatable?" is answered by math and a sweep, not opinion.
  • The golden master. Classic (Seal) is tuning-locked to a frozen trajectory fixture; any change that would perturb it fails CI. New systems land behind this gate, default-off, proven bit-identical.

This is why the entire currents program — a large gameplay system — landed with zero changes to the shipped game and could ship as a reviewable branch with no blast radius.
