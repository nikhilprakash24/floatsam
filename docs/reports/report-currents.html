§1 Executive summary

We answered one product question — how do currents enter the game? — and shipped a full, tested implementation skeleton across six phases on an isolated branch.

  • The design question is resolved, grounded in the code. The scrolling game fixes the player's x, so a whole-screen field only ever touches one vertical column. The everyday unit is therefore a localized cell that scrolls in like a gate; a whole-screen field is a rare Surge event.
  • Zero risk to the shipped game. Currents are opt-in and default-off; a bit-identical test proves the off path is byte-for-byte the old behavior. Classic's golden master and the 80,000-run fairness matrix are untouched.
  • Fairness is guaranteed by construction. Cells and surge share one budget clamp anchored to the weakest creature. The weakest reference bot still clears 8 gates through currents ~98% of the time.
  • Every design fork is a tunable variable, per direction — nothing hard-committed.

§2 The core decision

The engine has exactly one extension point: FluidField.sampleForce(x, y, t) returns an acceleration summed into the body. In the scrolling game the player's x is fixed, so a screen-anchored field is sampled at one column forever — a beautiful 2-D current collapses to a 1-D wobble.

So currents that you travel through must live in world coordinates and move. That reframes the whole feature: localized current cells are the grammar; a rare whole-screen Surge is the punctuation. The owner's instinct to keep the whole-screen effect rare is now the architecture, not a preference.

§4 Architecture

The seam

Currents plug into sampleForce and nowhere else — FluidBody, the game loop, and all locked Classic files are untouched.

Cells

A cell is a localized field built once in a local frame (x = 0), placed at a worldX that scrolls left. ScrollingCurrentField maps the body into each cell's frame, sums, and clamps. The spawner mirrors the pooled, seeded gate spawner, so replay, golden, and fairness all hold.

Surge

A seeded scheduler produces an envelope in [0,1] (idle → ramp-in → hold → ramp-out); the surge field is whole-screen turbulence + drift scaled by it, summed before the clamp so cells + surge share one escape budget.

Determinism

All fields are pure in (x, y, t); spawner and surge run on their own seeded streams — same seed, same run.

§5 Quality & fairness

  • 156 unit/sim tests green (44 new). Typecheck clean. Classic golden re-verified each phase.
  • Fairness by construction: a single budget clamp anchored to the weakest creature (Otter) — intensity can exceed 1.0 and the emitted force stays escapable.
  • G-Currents spot check (interim): 60 seeds × 4 creatures, currents-on Power Dive, reference bot — ≤1/60 failures (~98% clearance). The full 80k sweep + a frozen currents golden is the outstanding formal gate.
  • Bit-identical guard: currents-off is byte-for-byte identical whether the flag is omitted or explicitly false.
